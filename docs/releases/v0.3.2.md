Scenecast 0.3.2: Record records, in light or dark.

**Update:** click **Update** at the bottom left of Scenecast 0.3.1 (or **Check for updates**). Your demos stay where they are. If Scenecast then asks you to, click **Reload** (↻) on Scenecast Recorder at `chrome://extensions` (or `edge://extensions`).

**What's fixed**

- **Recording no longer stops with 0 screens when your computer is set to Dark.** 0.3.1 checked the system's appearance setting instead of how the pages actually looked, so on a Mac set to Dark it refused to start even with every app in light mode. The window then still said "Recording", and Stop reported "0 screens" in green.
- **Light or dark, it records.** Dark mode never blocks a recording now. Each screen keeps the theme it was recorded in, and the replica shows it that way on any computer, whatever that computer's own setting. Optional: set `"theme": "light"` or `"theme": "dark"` in a demo's `demo.json` and Scenecast tells you about any screen that doesn't match. It only tells you; it never blocks.
- **Failures are loud.** Recording shows only once the recorder has actually started. Until then the Record step says *Starting…*. If it can't start, it says why in red and offers **Try again**. Stop never reports 0 screens as a success.
- **An old recorder is caught.** Before recording, Scenecast checks that the recorder running in your browser is this version. If it isn't, Scenecast reloads it. If the browser won't let it, Scenecast says **Reload the recorder extension** and what to click.
- **Missing tabs are named.** If an app's tab isn't open, Record lists every app that's missing at once.
- **Clean-up:** the old hidden copy of the recorder (`~/.scenecast/extension`, from 0.3.0) is removed once no browser has it loaded. Demos made with 0.3.0's template no longer name the "Default" profile; they use the profile you have open.

**For developers**

- `node apps/desktop/tests/auditaur-smoke.mjs` records the fixture app through a dev build observed by [Auditaur](https://github.com/sethjuarez/auditaur). Auditaur's drive bridge clicks Start and Stop in the window, and its IPC log shows each command and what it returned. The run is isolated: it uses a temporary HOME, a test Chrome profile and its own receiver port.
