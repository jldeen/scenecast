Scenecast 0.3.1: the recorder just works, and the app updates itself from now on.

**Install:** download the installer for your system below, then follow the [one-page guide](https://github.com/jldeen/scenecast/blob/main/docs/guide.md) (also attached as `guide.pdf`). This is the last time you download one by hand: from 0.3.1 on, Scenecast tells you when there's a new version and **Update** installs it.

| | File |
|---|---|
| macOS (Apple silicon and Intel) | `Scenecast_0.3.1_universal.dmg` |
| Windows | `Scenecast_0.3.1_x64-setup.exe` (no admin), or `Scenecast_0.3.1_x64_en-US.msi` |

These installers aren't signed yet, so each system asks once:

- **Mac:** open Scenecast, click **Done** when macOS says it can't check it, then **System Settings → Privacy & Security → Open Anyway**.
- **Windows:** on "Windows protected your PC", **More info → Run anyway**. (If Edge holds the download: **… → Keep → Show more → Keep anyway**.)

**Coming from 0.3.0:** install 0.3.1 over it (your demos stay in Documents/Scenecast). Then, in your browser's extensions page, **remove** the old "Scenecast Recorder" and, on a demo's Record step, click **Install recorder**: it loads the new one from **Documents/Scenecast/Recorder Extension**.

**What's fixed**

- **The recorder connects.** The app now starts the receiver the extension talks to (with its own Node) as soon as a demo is open, keeps it running, and stops it when you quit. 0.3.0 only checked for it, so the extension said "Not connected" and every app waited on "needs the recorder connected".
- **No port to set.** The extension finds Scenecast by itself (and if 47621 is taken, the app uses the next free port and the extension finds that too). Its popup just says Connected.
- **Your real browser profile.** Scenecast finds the profile you have open (Profile 10, say) instead of assuming "Default". Pick a profile by its name on New demo or the Record step; it's saved with the demo. **Fix** opens a window for that profile in the browser you already have open: it never quits or restarts your browser or closes a tab.
- **Never stuck "busy (preflight)".** Pressing Check again, or Check and fix while a check runs, replaces the running check.
- The preflight list's app names no longer overlap their status.

**What's new**

- **Install recorder:** one button. It puts the extension in a folder you can see (Documents/Scenecast/Recorder Extension), opens the extensions page in your running browser and profile, shows the folder in Finder or File Explorer, and walks you through Developer mode and the drag with real pictures. It turns green the moment the recorder connects, and says in plain words what to do if something's off (Developer mode off, another profile, another browser).
- **When the recorder updates,** Scenecast reloads it for you (or tells you to click its Reload button).
- **In-app updates:** "Update available" at the bottom left, one click to update and restart. **Check for updates** asks now.
