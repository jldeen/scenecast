Scenecast 0.3.0: ready for anyone.

**Install:** download the installer for your system below, then follow the [one-page guide](https://github.com/jldeen/scenecast/blob/main/docs/guide.md) (also attached as `guide.pdf`).

| | File |
|---|---|
| macOS (Apple silicon and Intel) | `Scenecast_0.3.0_universal.dmg` |
| Windows | `Scenecast_0.3.0_x64-setup.exe` (no admin), or `Scenecast_0.3.0_x64_en-US.msi` |

These installers aren't signed yet, so each system asks once:

- **Mac:** open Scenecast, click **Done** when macOS says it can't check it, then **System Settings → Privacy & Security → Open Anyway**.
- **Windows:** on "Windows protected your PC", **More info → Run anyway**. (If Edge holds the download: **… → Keep → Show more → Keep anyway**.)

You need Microsoft Edge or Google Chrome.

**What's new**

- **The presenter guide** (⌥G / Ctrl+Alt+G): a second window for the laptop screen that follows the stage, with the talk track word for word, the clicks, watch-outs, a timer, and pictures of what's on screen now and next. Made from the same script as the focus points; **Start presenting** opens it on the app's screen. See [docs/presenter.md](https://github.com/jldeen/scenecast/blob/main/docs/presenter.md).
- **Fast checks:** after a build, a script or an edit, only what changed is checked (`scenecast quick`, a minute or two). The whole checklist runs once, on Export.
- Focus points made from the script follow wording and date edits; a focus mark against the screen's edge stays on screen.
- The "replicate a demo" skill for Copilot: `scenecast install-skill`.
- App keys never use G (the guide's key), as with F, N and P.
