Scenecast 0.4.1: signing in to GitHub Copilot works.

**Update:** click **Update** at the bottom left of Scenecast. Then on the **Copilot** page, **Sign in with GitHub** again.

**What's fixed**

- **"Copy the code and open GitHub" opens GitHub.** 0.4.0 copied the code but refused to open github.com/login/device ("not opening …").
- **The sign-in is kept.** After you approved the code, GitHub's sign-in couldn't reach the system keychain from inside the app and asked whether it may keep the sign-in in a file instead; 0.4.0 said no, so it went back to "Not signed in". Now it's kept in Scenecast's own Copilot folder, readable only by you (**Sign out** removes it).
- **Errors show.** If signing in fails, the Copilot page says why, with **Show the logs**. The app now keeps a log (`scenecast.log`, and `ai.log` for each sign-in step) in Scenecast's data folder.
